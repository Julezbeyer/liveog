# Contributing to LiveOG

LiveOG is pre-alpha. Contributions are welcome around rendering, framework adapters, compatibility research, examples, tests, and documentation.

Principles:
1. Never claim a social platform supports motion unless verified.
2. Always provide a static fallback path.
3. Keep the authoring API small and deterministic.
4. Prefer portable primitives over platform-specific hacks.

Open an issue before large architectural changes.
