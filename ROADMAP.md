# LiveOG Roadmap

Items link to tracking issues where one exists. Unassigned items are open for contributors. Checked items describe the source tree and may not yet be published on npm.

## v0.1 — Proof
- [x] React card primitives (`LiveCard`, `Animate`, `Counter`)
- [x] timeline/interpolation core
- [x] headless browser renderer
- [x] PNG export (last frame as poster)
- [x] MP4 export
- [x] GIF export (palette encoded)
- [x] animated WebP export
- [x] CLI with size, duration, fps and format flags
- [x] CI that renders PNG, MP4, GIF and WebP
- [x] metadata manifest (`og:image`, `og:video`, `twitter:card` snippet)
- [x] local preview with a timeline scrubber (CLI)
- [x] visual editor with five templates, animation presets and client-side export
- [x] automatic local drafts, including uploaded images and videos
- [x] GitHub stats demo
- [x] first npm release (v0.2.0)

## v0.2 — Ecosystem
- [x] Next.js App Router integration example
- [ ] Published Next.js adapter package
- [ ] Astro adapter
- [ ] Svelte adapter
- [ ] platform capability presets
- [ ] template API
- [x] easing and per-element timing in `Animate`
- [x] config file support in the CLI
- [x] Timeline-driven `CodeTyping` / `Typewriter` and `Sparkline` primitives

## Later — Experimental LiveOG manifest
- [ ] `liveog:manifest` proposal
- [ ] compatibility matrix built from platform reports
